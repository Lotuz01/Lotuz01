# Wendel de Paula Silva

### Engenharia de Dados | Python · SQL · PostgreSQL · Docker

Desenvolvo projetos de portfólio para transformar dados brutos em análises reproduzíveis, com foco em pipelines, modelagem SQL e indicadores de negócio.

## Competências demonstradas

- Pipeline de dados com camadas Raw, Staging e Marts.
- Ingestão e transformação com Python e SQL.
- PostgreSQL e Docker para execução local.
- Análise de desempenho logístico e integração com dados meteorológicos públicos.

## Projetos em destaque

### [Olist Data Warehouse](https://github.com/Lotuz01/projeto-engenharia-dados-olist)
Pipeline de Engenharia de Dados com Python, SQL, PostgreSQL e Docker. Organiza dados públicos do e-commerce Olist em camadas analíticas e gera indicadores de logística e frete.

### [Clima e desempenho logístico](https://github.com/Lotuz01/projeto-engenharia-dados-olist/tree/main/clima-logistica)
Extensão do projeto Olist que combina pedidos com clima histórico para explorar atrasos de entrega por estado e mês, com dashboard Streamlit.

### [Sistema de Planejamento de Recursos Empresariais](https://github.com/Lotuz01/Programa-de-Planejamento-de-Recursos-Empresariais)
Projeto web com TypeScript, Next.js e MySQL, incluindo painel de gestão e recursos de ERP.

## Tecnologias

`Python` · `SQL` · `PostgreSQL` · `Docker` · `pandas` · `Streamlit` · `TypeScript` · `Next.js` · `MySQL`
