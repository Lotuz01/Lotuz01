# Wendel de Paula Silva

### Desenvolvedor Web Full Stack | Backend · Frontend | Análise de Dados

Desenvolvo sistemas web e soluções de dados funcionais. Nos projetos abaixo, trabalho com interfaces, regras de negócio, APIs, bancos de dados, pipelines e indicadores analíticos.

## Sistemas e soluções desenvolvidos

### [Omnis Finals — Sistema de gestão empresarial](https://github.com/Lotuz01/Programa-de-Planejamento-de-Recursos-Empresariais)
Aplicação web com gestão de clientes, produtos e estoque, autenticação, dashboard e recursos de segurança. Desenvolvida com Next.js, TypeScript, API Routes, Prisma e MySQL.

### [Olist Data Warehouse](https://github.com/Lotuz01/projeto-engenharia-dados-olist)
Pipeline de dados que importa arquivos do e-commerce Olist, organiza os dados em camadas Raw, Staging e Marts e gera indicadores de logística e frete com Python, SQL, PostgreSQL e Docker.

### [Clima e desempenho logístico](https://github.com/Lotuz01/projeto-engenharia-dados-olist/tree/main/clima-logistica)
Solução que combina pedidos do Olist e dados meteorológicos históricos para analisar atrasos por estado e mês, com mart analítico e dashboard Streamlit.

## Tecnologias utilizadas

**Desenvolvimento web:** TypeScript · Next.js · Tailwind CSS · API Routes · Prisma · JWT · MySQL

**Análise e engenharia de dados:** Python · SQL · PostgreSQL · pandas · Streamlit · Docker
